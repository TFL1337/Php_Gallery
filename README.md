A simple and lightweight solution for running a photo gallery using PHP, Vue.js and charts.js.

Version 0.8 / 2026-11-06

Core features:
- Easy to host with minimum of configuration and installation
- Responsive web design for multi device usage
- Easy in use with core gallery features
  - Photo gallery build on file tree structure
  - On the fly index for image attributes and stastic creation
  - Rich filter options on image attributs
  - Image slideshow
- Enabled App installation on Android

Installation:

File structure<br/>
/root<br/>
-- /images<br/>
---- /(your galery folder)<br/>
------ (your images)<br/>
-- /thumbs<br/>
---- (auto created thumbnails for images of the images folder)<br/>
-- icon.png<br/>
-- php_gallery0.8.php<br/>
<br/>
(1) Create file structure and upload icon.png and php_gallery0.8.php<br/>
(2) Give access rights (rwx/777) to php_gallery0.8.php and /thumbs<br/>
(3) Copy your photos to /images<br/>
(4) Start php_gallery0.8.php and let the script do the job!<br/>
